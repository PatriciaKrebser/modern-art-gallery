# Modern Art Gallery

Sitio web responsive para una galería de arte moderno, desarrollado como proyecto frontend de ConquerBlocks.

## Tecnologías utilizadas

- HTML5
- Sass (SCSS)
- JavaScript
- Vite

## Características

- Diseño responsive y adaptable a distintos dispositivos.
- Página principal con presentación de la galería.
- Página de ubicación con información del establecimiento.
- Navegación entre páginas.
- Estados interactivos para los enlaces.

## Estructura del proyecto

```text
Modern Art Gallery/
├── assets/
│   ├── images/
│   └── icons/
├── css/
├── js/
├── sass/
├── index.html
├── location.html
├── package.json
└── vite.config.js
```

## Instalación

Clonar el repositorio e instalar las dependencias:

```bash
npm install
```

## Desarrollo

```bash
npm run dev
```

## Compilación para producción

```bash
npm run build
```

## Vista previa

```bash
npm run preview
```
